## Блок 1.1. Стеки

### A. Правильная скобочная последовательность

**Ограничение времени:** 1 с
**Ограничение памяти:** 64 МБ

#### Условие

Рассмотрим последовательность, состоящую из круглых, квадратных и фигурных скобок. Программа должна определить, является ли данная скобочная последовательность правильной.

Пустая последовательность является правильной.

Если `A` — правильная последовательность, то последовательности `(A)`, `[A]`, `{A}` — правильные.

Если `A` и `B` — правильные последовательности, то последовательность `AB` — правильная.

#### Формат ввода

В единственной строке записана скобочная последовательность, содержащая не более `100000` скобок.

#### Формат вывода

Если последовательность является правильной, вывести `yes`, иначе — `no`.

#### Примеры

**Пример 1**

```text
()[]

yes
```

**Пример 2**

```text
([)]

no
```

**Пример 3**

```text
(

no
```

#### Решение

Для проверки последовательности используется стек.

Открывающие скобки помещаются в стек. При встрече закрывающей скобки проверяется верхний элемент стека:

* стек пуст — последовательность некорректна;
* скобки соответствуют друг другу — открывающая скобка удаляется из стека;
* скобки не соответствуют — последовательность некорректна.

После обработки всей последовательности стек должен оказаться пустым.

#### Сложность

* **Время:** `O(n)`
* **Память:** `O(n)`

где `n` — количество скобок.

**Решение:** [`A.cpp`](lection-1-1/A.cpp)

### B. Минимальная ПСП

**Ограничение времени:** 1 с
**Ограничение памяти:** 64 МБ

#### Условие

Дана строка `s`, являющаяся началом правильной скобочной последовательности. Необходимо построить лексикографически минимальную ПСП длины `n`, состоящую из круглых и квадратных скобок и начинающуюся со строки `s`.

Порядок символов задаётся строкой `w` из четырёх различных скобок. Если `w = abcd`, то `a < b < c < d`.

Гарантируется, что ответ существует.

#### Формат ввода

В первой строке записано число `n` (`1 ≤ n ≤ 100000`).

Во второй строке записана строка `w`, состоящая из четырёх различных скобок.

В третьей строке записана строка `s`, длина которой не превосходит `n`.

#### Формат вывода

Вывести лексикографически минимальную правильную скобочную последовательность длины `n`, начинающуюся со строки `s`.

#### Примеры

**Пример 1**

```text
6
()[]
([(

([()])
```

**Пример 2**

```text
6
][)(
([

([][])
```

**Пример 3**

```text
4
(][)
()[]

()[]
```

#### Решение

Используется стек открывающих скобок.

Сначала обрабатывается заданный префикс `s`: открывающие скобки помещаются в стек, а при встрече закрывающейся скобки соответствующая открывающая скобка удаляется.

Затем ответ достраивается слева направо. На каждом шаге перебираются скобки в порядке `w` и выбирается лексикографически минимальный допустимый символ.

При добавлении открывающей скобки она помещается в стек. Закрывающая скобка может быть добавлена только в том случае, если она соответствует открывающей скобке на вершине стека.

#### Сложность

* **Время:** `O(n)`
* **Память:** `O(n)`

**Решение:** [`B.cpp`](lection-1-1/B.cpp)

### C. Поврежденный XML

**Ограничение времени:** 1 с
**Ограничение памяти:** 64 МБ

#### Условие

Дана XML-строка, в которой ровно один символ был заменён на другой. Необходимо восстановить исходную корректную XML-строку.

XML-строка состоит из открывающих и закрывающих тегов. Открывающий тег имеет вид `<X>`, а закрывающий — `</X>`, где `X` — непустая строка из строчных букв латинского алфавита.

XML-строка является корректной, если все открывающие и закрывающие теги правильно вложены и каждому открывающему тегу соответствует закрывающий тег с таким же именем.

Гарантируется, что входную строку можно сделать корректной заменой ровно одного символа. Если вариантов восстановления несколько, можно вывести любой.

#### Формат ввода

В единственной строке записана повреждённая XML-строка длиной от `7` до `1000` символов.

Строка содержит только строчные буквы латинского алфавита и символы `<`, `>` и `/`.

#### Формат вывода

Вывести любую корректную XML-строку, которую можно получить из входной строки заменой ровно одного символа на другой.

#### Примеры

**Пример 1**

```text
<a></b>

<b></b>
```

**Пример 2**

```text
<a><aa>

<a></a>
```

**Пример 3**

```text
<a><>a>

<a></a>
```

**Пример 4**

```text
<a/</a>

<a></a>
```

#### Решение

Для проверки корректности XML используется стек имён открытых тегов.

При встрече открывающего тега его имя помещается в стек. При встрече закрывающего тега проверяется, совпадает ли его имя с именем тега на вершине стека.

Для восстановления строки перебираются возможные изменения символов. Для каждого кандидата выполняется проверка полученной строки на корректность XML. Как только находится корректный вариант, он выводится.

Поскольку длина строки не превышает `1000`, такой перебор укладывается в ограничения задачи.

#### Сложность

Пусть `n` — длина строки.

В худшем случае перебирается `O(n)` позиций и до `O(26)` вариантов для каждой позиции, а каждая полученная строка проверяется за `O(n)`.

* **Время:** `O(26 · n²)`, то есть `O(n²)`
* **Память:** `O(n)`

**Решение:** [`C.cpp`](lection-1-1/C.cpp)
